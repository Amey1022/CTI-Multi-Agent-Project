## 5. Mitigation Plan

- **Response urgency:** Act within 24 hours.


### Immediate actions

- Isolate all compromised hosts (Windows servers, FortiOS devices, Exchange servers, ESXi hosts) from the network to stop lateral movement. - Play ransomware uses valid accounts for lateral movement; isolation prevents further spread. (T1078)
- Terminate malicious processes and delete identified ransomware binaries (e.g., SVCHost.dll backdoor, Gt_net.exe, HRsword.exe). - Unique, recompiled binaries evade AV; removing them stops execution. (T1027)
- Block outbound C2 traffic and disable any active Cobalt Strike/SystemBC sessions. - Cutting C2 prevents further commands and data exfiltration. (T1059.001)
- Stop the encryption process by killing the ransomware executable and removing scheduled tasks that launch it. - Halting encryption limits data loss (Data Encrypted for Impact). (T1486)
- Reset passwords and revoke tokens for any accounts that may have been compromised. - Valid accounts were abused for initial access; credential reset removes attacker persistence. (T1078)


### Prevention

- Apply all available patches for FortiOS, Microsoft Exchange, SimpleHelp RMM, and VMware ESXi within 24 hours. - Exploitation of these public‑facing vulnerabilities is the primary initial‑access vector. (T1190)
- Enforce multi‑factor authentication (MFA) for all privileged and remote accounts. - MFA mitigates abuse of stolen or purchased valid credentials. (T1078)
- Segment networks to isolate critical systems (e.g., Exchange, ESXi) from general user zones. - Network segmentation limits attacker movement after initial compromise. (T1190)
- Disable unnecessary external services such as RDP and VPN for accounts that do not require them. - External‑facing services are used for initial access. (T1190)
- Deploy application isolation or sandboxing for web‑exposed services. - Isolation reduces the impact of a successful exploit. (T1190)


### Detection

- Enable PowerShell Script Block Logging (Event ID 4104) and alert on encoded or obfuscated commands. - PowerShell is used for remote code execution and C2. (T1059.001)
- Monitor for service stop or configuration changes to Windows Defender, GMER, IOBit, or other security tools. - Attackers disable endpoint protection to evade detection. (T1562.001)
- Alert on mass file renaming to the .PLAY extension or creation of ransom notes in C:/Users/Public/Music/ReadMe.txt. - These are indicators of the encryption phase. (T1486)
- Log and alert on login attempts from unusual locations, times, or using dormant privileged accounts. - Valid‑account abuse is a key initial‑access method. (T1078)
- Scan newly created binaries for high entropy or packing characteristics. - Recompiled ransomware binaries are obfuscated to avoid AV detection. (T1027)


### Recovery

- Restore encrypted data from verified, offline backups after confirming the environment is clean. - Backups provide a reliable path to recover without paying ransom.
- Conduct a full credential reset for all domain and service accounts. - Credential dumping tools like Mimikatz may have harvested passwords.
- Perform a post‑incident threat‑hunt to locate any remaining malicious artifacts or persistence mechanisms. - Ensures complete eradication before returning to production.
- Document the incident timeline, IOCs, and lessons learned; update incident response playbooks. - Improves future detection and response capabilities.
