5. Mitigation Plan

  • Response urgency: Act within 24 hours.

Immediate actions

  • Isolate compromised workstations and servers from the network - Stops lateral movement and C2 communication associated with Ingress Tool Transfer (T1105) and ransomware encryption (T1486) (T1105, T1486)
  • Terminate malicious processes such as gaze.exe and any suspicious PowerShell scripts - Halts execution of the ransomware payload and PowerShell-based obfuscation observed in the incident (T1059.001, T1105)
  • Delete or quarantine malicious files (gaze.exe, mimilib.dll, PDQ Deploy scripts) - Removes the tools used for execution, credential dumping and file transfer (T1027, T1003)
  • Reset compromised credentials and enforce privileged account management - Mitigates credential theft performed by Mimikatz (mimilib.dll) (T1003)
  • Enable PowerShell Script Block Logging (Event ID 4104) and enforce execution policy - Detects and blocks encoded/obfuscated PowerShell commands used by the adversary (T1059.001)
  • Restore encrypted files from known good backups after verifying integrity - Recovers data encrypted with AES‑256 and mitigates impact of ransomware (T1486)

Prevention

  • Apply security patches promptly to all operating systems and software - Reduces exploitable vulnerabilities that enable initial access and scanning
  • Implement application whitelisting and code signing for executables - Prevents unauthorized tools like gaze.exe and PDQ scripts from running
  • Enforce least‑privilege and privileged account management policies - Limits ability of tools such as Mimikatz to dump credentials (T1003)
  • Disable or restrict use of certutil, bitsadmin, and other native utilities for file download - Blocks common ingress tool transfer mechanisms (T1105)
  • Deploy network segmentation and intrusion prevention systems to block internal port scans - Stops network service scanning (T1046) and limits lateral movement (T1046)
  • Maintain regular, offline, immutable backups of critical data - Ensures recovery capability against data encryption attacks (T1486)

Detection

  • Monitor for high‑entropy or base64‑encoded PowerShell command lines and alert on bypass flags - Detects obfuscated PowerShell payloads used in the attack (T1059.001)
  • Alert on creation of files from external sources or unusual locations (e.g., System32) - Catches ingress tool transfer such as PDQ Deploy copying gaze.exe (T1105)
  • Detect credential dumping activity by monitoring access to LSASS and loading of mimilib.dll - Identifies OS Credential Dumping behavior (T1003)
  • Log and alert on internal hosts contacting many ports or hosts in short timeframes - Identifies network service scanning activity (T1046)
  • Watch for mass file modifications, new file extensions, and ransom note files - Signals ransomware encryption phase (T1486)
  • Enable PowerShell transcription and script block logging to capture full command history - Provides forensic evidence and real‑time detection of malicious scripts (T1059.001)

Recovery

  • Reimage affected systems from clean baselines after ensuring removal of malicious artifacts - Guarantees that no residual malware remains
  • Restore data from verified backups and verify file integrity before bringing systems back online - Recovers encrypted data and minimizes downtime
  • Rotate all privileged credentials and enforce strong password policies - Mitigates risk from previously dumped credentials
  • Conduct a post‑incident review to update detection rules and hardening controls - Improves future resilience based on observed TTPs
  • Communicate with stakeholders about the incident and remediation steps taken - Ensures transparency and aligns response actions
  • Validate that PowerShell logging and endpoint behavior prevention are fully operational - Confirms that detection/prevention measures are active for future attacks
